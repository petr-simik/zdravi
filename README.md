# Zdraví

Osobní aplikace na telefon: plán tréninků se zápisem výkonů, denní návyky, tělesné metriky, suplementy a zdravotní úkoly. Celá česky, funguje i bez připojení.

Data se ukládají jen v zařízení (IndexedDB). V repozitáři nejsou žádná osobní data, vlastní plán se do aplikace nahrává ze souboru.

## Vývoj

```bash
npm install
npm run dev
```

Push na `main` aplikaci sestaví a nasadí na GitHub Pages.

Aplikace jen zaznamenává a zobrazuje. Není to lékařská péče a nic nediagnostikuje.
